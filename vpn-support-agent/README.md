# VPN Support Agent (v1)

AI-бот поддержки для VPN-сервиса: **Telegram** (канал) + **Claude** (мозг) + **Composio → Google Таблица** (запись жалоб). Отвечает на частые вопросы из базы знаний, фиксирует обращения в таблицу и (опционально) уведомляет администратора о серьёзных проблемах.

## Как это устроено

```
Пользователь ──Telegram──▶ [этот бот] ──▶ Claude (рассуждает, отвечает)
                                  │
                                  ├─ log_issue ──────▶ Composio ──▶ Google Таблица (жалобы)
                                  └─ escalate_to_admin ─▶ Telegram (чат админа)
```

- **Мозг** — Claude (Anthropic). Composio мозг НЕ даёт, поэтому нужен отдельный ключ.
- **Руки** — Composio выполняет действие «записать строку в Google Таблицу».
- **Канал** — Telegram-бот (long polling, без домена и сервера-фронта).

## Что нужно подготовить (4 вещи)

| # | Что | Где взять |
|---|-----|-----------|
| 1 | Ключ **Anthropic** (`sk-ant-…`) | console.anthropic.com → Billing → API Keys |
| 2 | Токен **Telegram-бота** | @BotFather в Telegram |
| 3 | Ключ **Composio** (`ak_…`) + подключённый Google Sheets | dashboard.composio.dev |
| 4 | **Google Таблица** (её ID) | docs.google.com/spreadsheets |

### 1) Ключ Anthropic (мозг бота)
1. Зайди на **https://console.anthropic.com** и зарегистрируйся.
2. **Billing → Credits**: пополни баланс (минимум ~$5; на тестах хватит надолго).
3. **Settings → API Keys → Create Key**, скопируй ключ вида `sk-ant-...`.
4. Вставь его в `.env` как `ANTHROPIC_API_KEY`.

Стоимость зависит от модели (см. раздел «Модель и цены» ниже). По умолчанию стоит **Haiku** — самый дешёвый, для FAQ-поддержки этого достаточно.

### 2) Токен Telegram-бота
1. В Telegram открой **@BotFather** → команда `/newbot`.
2. Задай имя и username бота.
3. BotFather пришлёт токен вида `123456:ABC...` → вставь в `.env` как `TELEGRAM_BOT_TOKEN`.
4. (Необязательно) Чтобы получать срочные уведомления: напиши боту **@userinfobot**, узнай свой `id`, вставь в `TELEGRAM_ADMIN_CHAT_ID`.

#### Вариант: бот отвечает от лица рабочего аккаунта (Telegram Business)
Если поддержка ведётся с обычного аккаунта (с номером телефона), бот может отвечать
**прямо в личных чатах этого аккаунта** — клиенты пишут человеку, отвечает бот.
Это официальный механизм Telegram, код уже его поддерживает. Что нужно:

1. На рабочем аккаунте должна быть активна подписка **Telegram Premium** (Business-функции входят в неё).
2. В **@BotFather**: выбери бота → *Bot Settings* → включи **Business Mode**.
3. На рабочем аккаунте: *Настройки → Telegram Business → Чат-боты* → введи username бота
   и дай ему право **отвечать на сообщения**.
4. Запусти бота как обычно (`python main.py`). Сообщения клиентов рабочему аккаунту
   начнут приходить боту, и он будет отвечать от имени аккаунта.

Нюансы:
- Свои собственные (написанные вручную) ответы владельца бот игнорирует — автоответ
  только на входящие от клиентов.
- В настройках Business можно исключить отдельные чаты из-под бота.
- ❗ НЕ используй «вход в аккаунт по номеру телефона» для автоматизации (userbot через
  MTProto): это риск блокировки рабочего номера и передача полного доступа к аккаунту.
  Business-подключение — безопасная официальная альтернатива.

### 3) Composio + подключение Google Sheets
1. Зайди на **https://dashboard.composio.dev**, ключ `ak_...` → в `.env` как `COMPOSIO_API_KEY`.
   > ⚠️ Старый ключ засветился в чате — **перевыпусти его** (Settings → API Keys) и используй новый.
2. **Auth Configs → Create** → выбери **Google Sheets** → режим **Composio-managed OAuth** (свой client_id/secret НЕ нужен) → создай.
3. **Connected Accounts → Connect** → Google Sheets → войди в свой Google-аккаунт и разреши доступ.
   - Важно: подключай под тем же **user id / entity**, что указан в `.env` как `COMPOSIO_USER_ID` (по умолчанию `vpn-admin`).
4. Проверка: при запуске `main.py` бот сам напишет `Google Sheets: ✅ подключён` или `❌`.

### 4) Google Таблица
1. Создай новую таблицу на docs.google.com (в том же Google-аккаунте, что подключил в Composio).
2. Назови вкладку, например, `Жалобы`, и впиши заголовки в первую строку:
   `Дата | Категория | Сервер/Страна | Серьёзность | Описание`.
3. Скопируй ID из URL: `docs.google.com/spreadsheets/d/`**`<ЭТО_ID>`**`/edit` → в `.env` как `GOOGLE_SHEET_ID`.
4. `GOOGLE_SHEET_NAME` = имя вкладки (`Жалобы`).

## Запуск

```bash
cd vpn-support-agent
cp .env.example .env          # затем заполни .env своими значениями
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Бот напечатает статус конфигурации и начнёт отвечать в Telegram. Напиши боту `/start`.

### Через Docker
```bash
docker build -t vpn-support-agent .
docker run --env-file .env vpn-support-agent
```

### Хостинг 24/7
Чтобы бот работал постоянно, разверни контейнер на любом VPS / Fly.io / Render / Railway и задай переменные окружения из `.env`. Long polling не требует публичного домена.

## Модель и цены (Anthropic)

| Модель | ID (в `.env`) | Вход / Выход за 1M токенов | Когда |
|--------|---------------|----------------------------|-------|
| Haiku 4.5  | `claude-haiku-4-5`  | $1 / $5   | **по умолчанию** — дёшево, быстро, для FAQ |
| Sonnet 4.6 | `claude-sonnet-4-6` | $3 / $15  | если нужны ответы поумнее |
| Opus 4.8   | `claude-opus-4-8`   | $5 / $25  | самые сложные диалоги |

Для бота поддержки **Haiku** — правильный выбор по соотношению цена/качество. Поменять — одна строка в `.env`.

## Как улучшать бота

- **База знаний** — редактируй `knowledge_base.md`. Бот отвечает строго по нему; чем подробнее, тем лучше. Перезапусти бот после изменений.
- **Поведение/тон** — правь `SYSTEM_PROMPT_TEMPLATE` в `agent.py`.
- **Новые действия** — добавь инструмент в список `TOOLS` и обработчик в `agent.py` (например, создание задачи в GitHub Issues — тулкит `github` в Composio уже доступен).

## Чего пока НЕТ (следующие шаги)

- **RAG / семантический поиск по базе** — сейчас весь FAQ кладётся в промпт. Для большой базы знаний понадобится векторный поиск.
- **Ежедневный отчёт (PM-агент)** — отдельный скрипт по расписанию (cron), который собирает жалобы из таблицы и шлёт сводку.
- **Отзывы из App Store / Google Play** — у Composio нет нативной интеграции; нужен App Store Connect / Google Play API отдельно.
- **CRM по подпискам** — источник правды (RevenueCat/App Store) шлёт webhook на backend, дальше Composio делает действия.

## Безопасность
- Никогда не коммить `.env` (он уже в `.gitignore`).
- Ключи (`sk-ant-…`, `ak_…`, токен бота) — это секреты. Если засветились — перевыпусти.
- VPN — приватный продукт: подключай в Composio минимум прав и осознанно решай, какие данные куда идут.
