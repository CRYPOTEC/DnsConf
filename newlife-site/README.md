# Новая — концепт-редизайн сайта застройщика

Современный многостраничный сайт для застройщика «Новая» (Ульяновск) —
переосмысление [newlife-ul.ru](https://newlife-ul.ru/) в премиальном тёмном
стиле с моушен-эффектами.

Проект собран по мотивам Instagram-ролика о вёрстке сайтов «из терминала»:
**Claude Code + Framer Motion** (стек из ролика воспроизведён по-настоящему;
платные инструменты «UI/UX Pro Max» и 21st.dev заменены ручной реализацией
того же класса).

## Стек

- **React 19** + **TypeScript** + **Vite**
- **Tailwind CSS v4** — дизайн-система через `@theme`-токены
- **Framer Motion** — анимации появления, параллакс, тилт, счётчики, marquee
- **React Router** — многостраничная навигация с переходами
- **lucide-react** — иконки

## Страницы

| Маршрут | Описание |
|---|---|
| `/` | Главная: hero, статистика, проекты, акции, преимущества, новости, CTA |
| `/newlife` | ЖК «Новая Жизнь» — концепция, галерея, заявка |
| `/naganova` | ЖК «Новая Наганова» |
| `/apartments` | Каталог квартир с фильтром по комнатности |
| `/mortgage` | Интерактивный калькулятор ипотеки |
| `/about` | О компании: миссия, таймлайн, география |
| `/contacts` | Контакты и форма заявки |

## Дизайн-система

- Тёмная база (`--color-base`) + единый изумрудный акцент (`--color-brand`)
- Крупная дисплейная типографика (Unbounded) + читаемый текст (Manrope), кириллица
- Стекло (`.glass`), сетка-фон (`.bg-grid`), мягкое свечение (`.glow-brand`)
- Единая кривая плавности `EASE` для всех анимаций

## Запуск

```bash
npm install
npm run dev       # дев-сервер
npm run build     # продакшен-сборка (tsc + vite)
npm run preview   # предпросмотр сборки
```

> Формы отправляют заявку в демонстрационном режиме (без бэкенда).
