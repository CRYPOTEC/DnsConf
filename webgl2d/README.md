# WebGL 2D Renderer

Маленькая библиотека 2D-рендеринга на **WebGL2** + демо-сайт. Без внешних
зависимостей рантайма (только Vite как dev-сервер/сборщик).

Возможности:

- **Инстансный рендеринг** — тысячи объектов рисуются одним `drawArraysInstanced`.
- **Камера**: зум к курсору (колесо) и панорама (перетаскивание фона).
- **Drag-n-drop**: фигуры можно хватать и таскать; подпись едет вместе с фигурой.
- **Чёткий текст**: SDF-атлас шрифта генерируется на лету (алгоритм Felzenszwalb
  & Huttenlocher). Текст остаётся резким на любом масштабе. Латиница + кириллица.
- **Фигуры**: прямоугольники и сглаженные круги/эллипсы, поворот, прозрачность.
- Демо со **сценой из 3000 объектов** с подписями.

## Запуск

Нужен Node.js 18+.

```bash
cd webgl2d
npm i
npm run dev
```

Vite сам откроет браузер (обычно http://localhost:5173). Сборка статики:

```bash
npm run build     # результат в dist/
npm run preview   # локальный предпросмотр сборки
```

## Управление

| Действие              | Как                              |
| --------------------- | -------------------------------- |
| Зум                   | колесо мыши (к точке под курсором) |
| Панорама              | тащить пустое место              |
| Переместить объект    | тащить фигуру (drag-n-drop)      |
| Сбросить вид          | клавиша **R**                    |

```
        ├── index.js      # публичный API
        ├── Renderer.js   # WebGL2-контекст, ресайз, цикл, блендинг
        ├── Camera.js     # ортокамера, зум/пан, world<->screen
        ├── Controls.js   # мышь/тач: зум, панорама, drag-n-drop
        ├── Scene.js      # фигуры + подписи, пикинг, перемещение
        ├── ShapeBatch.js # инстансные прямоугольники/круги

        ├── FontAtlas.js  # генерация SDF-атласа шрифта
        └── gl.js         # компиляция/линковка шейдеров
```

## Как пользоваться библиотекой

```js
import { Renderer, Scene, Controls, FontAtlas } from './lib/index.js';

const renderer = new Renderer(document.querySelector('canvas'));
const atlas = new FontAtlas({ fontSize: 46 }).build('ABCabc123Привет');
const scene = new Scene(renderer, atlas);

scene.addShape({ x: 0, y: 0, w: 120, h: 80, color: [0.3, 0.7, 1, 1], label: 'box' });
scene.addShape({ x: 200, y: 0, w: 90, h: 90, shape: 1, color: [1, 0.5, 0.2, 1] });
scene.addText(0, -160, 'Заголовок', 64, [1, 1, 1, 1]);
scene.upload();

new Controls(renderer, scene);
renderer.run(() => {
  renderer.clear(0.05, 0.06, 0.09, 1);
  renderer.camera.updateMatrix();
  scene.draw(renderer.camera.matrix);
});
```

## Заметки по реализации

- Координаты мира: ось **Y вниз** (как у экрана). Камера строит 3×3-матрицу
  `world → clip` и передаёт её одним `uniformMatrix3fv`.
- Текст хранится в мировых координатах: для каждой подписи заранее вычисляются
  квады глифов, поэтому перерисовка — это только смена матрицы камеры. При
  перетаскивании объекта обновляется лишь его диапазон глифов (`bufferSubData`).
- SDF пакуется в одноканальную текстуру `R8`; в шейдере резкость даёт
  `smoothstep` по `fwidth` поля расстояний.
- Рассчитано на десктоп (зум — колесо мыши). Мультитач-пинч не реализован.
