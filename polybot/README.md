# polybot — бумажный бот для Polymarket на новостях

Бот, который **в бумажном режиме** (без реальных денег) торгует на
[Polymarket](https://polymarket.com): читает новостные ленты, ловит
высказывания/события по заданным рынкам и совершает **виртуальные** сделки
по реальным рыночным ценам. Цель — проверить, есть ли у стратегии
«новость → сигнал → ставка» реальное преимущество (edge), **прежде чем**
рисковать деньгами.

> ⚠️ Это симулятор. Здесь нет размещения настоящих ордеров и нет кошелька.
> Живое исполнение (CLOB API + кошелёк USDC) — отдельный, защищённый этап,
> к которому переходим только после положительной статистики на бумаге.

## Почему именно так

- **Скорость.** На новостях ты конкурируешь с низколатентными ботами.
  Бумажный режим честно покажет, успеваешь ли ты по цене.
- **Манипуляция.** Заголовок может быть фейком или двусмысленным
  (см. `news.py` — контент лент считается недоверенным). На бумаге ошибка
  стоит 0 рублей.
- **Дисциплина риска.** Лимиты на ставку и позицию, кулдаун, стартовый
  «депозит» — всё уже встроено и обкатывается на симуляции.

## Требования

Только **Python 3.10+** и стандартная библиотека. Зависимостей нет.

## Быстрый старт

```bash
cd polybot

# 1. посмотреть активные рынки и их slug'и
python -m polybot markets --limit 15

# 2. создать локальный конфиг из примера
python -m polybot init           # создаст config.json

# 3. отредактировать config.json: вписать slug нужного рынка
#    и ключевые слова (см. ниже)

# 4. прогнать один цикл
python -m polybot run --once

# 5. крутить в цикле (Ctrl+C — стоп)
python -m polybot run --loop

# посмотреть портфель
python -m polybot status
```

## Конфиг (`config.json`)

| поле | смысл |
|------|-------|
| `starting_cash` | стартовый виртуальный баланс USDC |
| `stake_usd` | размер одной ставки |
| `max_position_usd` | потолок вложений в одну (рынок, исход) |
| `min_confidence` | минимальная уверенность сигнала (0..1) |
| `slippage_bps` | проскальзывание относительно котировки |
| `cooldown_sec` | пауза между сделками по одному исходу |
| `poll_interval_sec` | период опроса в режиме `--loop` |
| `news_feeds` | список RSS/Atom-лент |
| `watchlist` | какие рынки отслеживать (см. ниже) |

### Элемент watchlist

```json
{
  "slug": "us-x-iran-permanent-peace-deal-by-june-15-2026-734-856-129",
  "match_keywords": ["iran", "tehran"],
  "bull_keywords": ["peace deal", "agreement", "ceasefire"],
  "bear_keywords": ["strike", "attack", "war", "talks fail"]
}
```

- `match_keywords` — относится ли новость к этому рынку вообще.
- `bull_keywords` — слова, толкающие исход **Yes** вверх → бот покупает Yes.
- `bear_keywords` — слова в пользу **No** → бот покупает No.
- Если в одной новости есть и то, и другое (противоречие) — сделки нет.

Уверенность растёт с числом совпадений и если ключевое слово в заголовке.

## Как это устроено

```
news.py        RSS/Atom → NewsItem        (контент недоверенный!)
polymarket.py  Gamma API → Market (цены)  (только чтение)
signals.py     news + правила → Signal    (детерминированно, тестируемо)
paper.py       Portfolio + PaperBroker    (виртуальные сделки, P&L)
engine.py      цикл: news→signals→trades→state
storage.py     state.json (переживает рестарт, не торгует дважды)
cli.py         команды markets/news/run/status/init
```

   риск-лимитами, kill-switch и (для крупных ставок) ручным подтверждением.
   Включается только после стабильно положительной бумажной статистики.
