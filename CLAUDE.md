# О репозитории

ВАЖНО: этот репозиторий — универсальный «склад» для всех проектов пользователя.
Его название (DnsConf) ничего не значит и не описывает содержимое — не делайте
выводов о назначении репозитория по его имени. Здесь могут сосуществовать
совершенно разные, не связанные между собой проекты (Java/Maven, Node.js,
Remotion и т.д.), каждый в своей подпапке.

При добавлении нового проекта размещайте его в отдельной подпапке в корне
репозитория, не смешивая с другими проектами.

## Текущее содержимое

- `src/`, `pom.xml` — Java/Maven-проект (DNS-конфигурация), исходный проект репозитория.
- `remotion-demo/` — Node.js-проект на Remotion (генерация видео кодом на React).
